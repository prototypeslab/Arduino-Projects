## Libraries and setup

The `libraries/` folder contains the bundled libraries used by these projects. Individual projects may also include their own dependencies. Open the sketch or project in its corresponding IDE and select the appropriate board and hardware configuration.

Some projects use older toolchains and library versions. Refer to the accompanying blog posts and the files within each project for hardware details and setup.

Configure your own Wi-Fi credentials and service keys before running network examples. Non-placeholder credentials found during publication preparation were replaced with `YOUR_WIFI_SSID`, `YOUR_WIFI_PASSWORD`, and `YOUR_ADAFRUIT_IO_KEY`.

Project images, videos, documentation, and bundled dependencies are included. Local operating system metadata, IDE user state, and selected generated build files are excluded from version control.
